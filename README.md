# USB Bridge Desk R3 · 1.1.0

同一份 Windows x64 安装包可用于两台电脑。插有 USB 设备的一端选择「共享本机 USB」，需要使用设备的一端选择「连接远端 USB」。R3 使用 C# 与 WinUI 3 原生控件。安装包名为 `USB-Bridge-Desk-R3-1.1.0-x64.exe`。

## 安装

1. 系统要求为原生 x64 Windows 10 22H2 或 Windows 11。安装驱动和服务需要管理员权限。由 1.0.1 升级时，先安全弹出存储设备、断开映射、停止共享并退出旧版，然后卸载旧应用。请保留用户目录中的 `profiles.json`。
2. 在两台电脑上分别运行安装包。安装程序检测共享运行时，按需从 Microsoft 下载 x64 .NET Desktop Runtime 10.0.15 和 Windows App Runtime 1.8。已有兼容版本时会复用。运行时缺失且无法访问 Microsoft 时，安装会停止并给出日志。外层安装包未签名。
3. usbipd 共享引擎、原厂驱动安装材料和 usbip-win2 客户端随包提供。使用开始菜单的「USB Bridge Desk」打开应用，按安装提示重启。独立安装的 USB/IP 服务或 VirtualBox 监控驱动冲突时，安装程序会给出提示。
4. 首次启动会尝试读取旧版漫游用户目录 `usb-bridge-desk\profiles.json` 或 `USB Bridge Desk\profiles.json`。新版配置和启动日志保存在 `%LOCALAPPDATA%\USB Bridge Desk`。已保存映射会重新向控制器确认当前端口。

## 共享设备

在设备所在电脑打开「共享本机 USB」，启动服务。选择设备后点击「共享所选」，每批最多 6 个。设备状态会显示未共享、已共享、使用中或已拔出。停止共享前请让客户端结束读写。共享服务使用 TCP 3240，新装服务为手动启动。页面中的本机地址可按网卡选择和复制。

## 连接远端

| 方式 | 共享端或网络准备 | 连接端填写 |
|---|---|---|
| UU 远程 | 在 UU 主控端的被控电脑端口映射面板创建 TCP 规则，远端指向 127.0.0.1:3240，保持被控端在线、映射面板开启。 | 选 UU 远程，地址锁定为 127.0.0.1。端口填写 UU 规则的实际本地端口，例如 13240。每台被控端使用独立端口。 |
| EasyTier | 两台电脑进入同一可信虚拟网。在「共享本机 USB」查看共享端的虚拟网卡地址。 | 填共享端的虚拟 IP，默认端口 3240。 |
| TCP 直连 | 确保共享端地址可达且允许 TCP 3240。随包防火墙规则限制为本地子网。 | 填共享端 IP 或主机名，默认端口 3240。 |

在「连接远端 USB」添加目标，点击「发现设备」，勾选并「连接所选」。转到「映射列表」查看对应虚拟端口，再用设备管理器和原设备软件核实功能。目标端口可选 1024–65535，最多 24 个目标、60 条映射。切换目标地址或传输方式前，先断开该目标的设备。UU 的建议端口会跳过已保存的回环端口，建规则仍需在 UU 面板中完成。

## 重连、托盘和外观

- 窗口打开或驻留托盘时，应用检查虚拟控制器。重连前核对地址、端口、总线 ID、VID 和 PID。取消重连会先保存意图，控制器暂不可用时显示「等待释放」。同型号同 VID/PID 设备互换仍需人工核对。
- 默认关闭窗口会转入托盘。双击恢复，右键可打开主窗口、查看映射或退出。托盘状态随组件和连接状态变化。Windows 通知设置会影响气泡显示。退出会停止应用监测，已有驱动映射可在退出前手动断开。
- 「设置」可选跟随系统、浅色、黑夜，切换云母或桌面亚克力，并调整减弱动效和关闭到托盘。材质呈现受系统版本、透明效果、节电和远程会话影响。Ctrl+Shift+S 可保存当前可见窗口的 PNG。
- USB/IP 协议本身没有认证或加密。请在可信网络或隧道中使用。存储设备断开前须结束读写并安全弹出。HASP / Sentinel 等设备兼容性须以实际设备测试为准。

## 诊断与卸载

主窗口先呈现，随后异步读取共享服务及虚拟控制器。引擎缺失或故障会在对应页面显示。运行时初始化异常有原生 Win32 提示和 `%LOCALAPPDATA%\USB Bridge Desk\startup.log`。若 .NET 尚未启动，Windows 应用宿主可能直接提示缺少运行时，请重新运行安装器。运行时、服务或驱动安装详情见安装器详细输出和 `%TEMP%\usb-bridge-*.log`。在「设置 → 第三方许可」可查看许可证及对应源码。

卸载前断开映射、停止共享服务，再从托盘退出。通过 Windows 的已安装应用卸载。共享运行时供其他程序复用，个人设置保留。

## 从同一份源码构建

需要 .NET SDK 10.0.404、Python 3.11+、NSIS 3.11，以及访问 NuGet 和上游发布站点的网络。源码中带有固定版 USB/IP 上游源码。脚本在构建前校验上游引擎安装资产的 SHA-256。Windows 和 Linux 都可构建 x64 安装器。图形、驱动和 USB 实机验收需要 Windows。

```text
python dev/package.py
```

可用 DOTNET、MAKENSIS 指定可执行文件路径。输出在 release/。单独运行 C# 回归测试可使用 `dotnet run --project Tests -c Release`。App/ 是 WinUI 窗口、设备适配和托盘，Core/ 为传输配置、解析、映射与重连，packaging/ 为安装脚本。dev/build-host.py 从 usbipd-win 5.3.0 对应源码生成服务端和 CLI。dev/package.py 先生成交付源码 ZIP，在新目录解开后编译该副本、运行测试，再打包其产物。安装器的 notices/ 含原样源码 ZIP 及构建文件哈希清单。

图形验收应在交互式 Windows 桌面进行。dev/capture-windows.ps1 按提示采集六种实际画面，并记录 PNG 哈希、系统版本和被测程序哈希。测试报告列出本次已完成与待验证的项目。
